Claude 2.0 新功能一次讲清：Anthropic 把桌面端彻底改版，Claude Code 成了更新主战场，从会话管理到 mods 都能自己配。看完你能照着把 11 个更新逐个打开用上。
	
1️⃣ Claude 2.0 总览：桌面端只剩 chat 和 code，Cowork 并进 chat，Claude Code 成了主战场
2️⃣ 会话栏：右侧面板显示环境、上下文占用和连接器，一眼看出额度被什么吃掉
3️⃣ 分区与嵌套会话：对话能分进分区当文件夹，一个会话还能再开子会话并回收结果
4️⃣ 主会话：置顶一个会话，让它替你翻其他对话、汇总等你拍板的决定
5️⃣ 云端项目：项目跑在 Anthropic 云上，关掉设备也继续，还能共享自定义记忆
6️⃣ 旁支对话与分屏：不打断主任务的提问用旁支对话，分屏最多同时摆十个会话
7️⃣ 文档与幻灯片：Docs、Slides、Design、仪表盘、Claude Motion 都在 Claude 里产出 artifact
8️⃣ 斜杠命令：Output Style、Doctor、Advisor、Insights、Recap、Rewind 各管一件事
9️⃣ Mods 与快捷键：用一句话做 mod 改界面，再用快捷键把 Claude 叫到任何地方
	
✅ 总结：这版的重点不是加功能，而是把会话、项目、产物和界面收进一个可编排的工作台。先开主会话和分区，再装 mods，收益最快。
