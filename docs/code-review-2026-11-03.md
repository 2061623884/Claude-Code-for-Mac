## 模块边界

- `claudeConfigProtocol` 负责 SDK 控制协议适配与结构校验。
- `claudeConfigAccess` 负责应用内原生配置操作顺序。CLI 用户级配置跨项目共享，因此使用全局队列。
- `claudeConfigSnapshot` 负责协调目录读取、SDK 状态和用户偏好。
- `claudeConfigValues` 保持纯值推导，只输出设置目录中的标量值。
- `useClaudeConfig` 负责页面请求生命周期，`ClaudeConfigSettings` 负责表单渲染。
- `SessionRuntimes` 保持运行实例和占用管理的单一入口。已有的占用测试覆盖并发问答、容量回收、空闲回收、显式重载和退出。

侧栏图标的可访问计数始终保留，展开时只隐藏可见数字。修正一条依赖旧 SVG 结构的测试，没有为迁就测试回退现有界面。

## 边界

- 配置队列只协调本应用内操作，不能锁住外部终端中同时执行的配置写入。
- get_settings 仍是 SDK 私有控制协议。升级 SDK 后必须重新核对；结构不兼容时明确报错。
- 原生默认值只对已审阅的 CLI 2.1.301 进行推导，其他版本未知值保持未知。
- 测试使用合成 SDK 数据和临时目录，不发送真实模型对话，也不修改用户真实 Claude 设置。
- 本次发布沿用 Apple Silicon arm64，未使用 Apple Developer ID 签名或公证。
- 本地日志、视频笔记和设计素材不进入本次 Git 提交或 Release 附件。
