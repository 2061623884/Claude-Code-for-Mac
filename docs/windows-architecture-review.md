# Windows 预览版架构审查与修复

审查基线：`7ab9a88bba03d0ab0b55baec749b9950286f6bd3`。范围为 Windows 原生适配的工作区改动、新增模块及相关跨平台调用方；分别核对结构与已确认需求。

## Standards

- 发现 Windows 路径规则分散在正文识别、粘贴输入和变更文件显示中，导致反斜线、盘符和带空格路径支持不一致。判断为重复知识与修改分散，而非工具可检查的语法问题。
- 修复：`shared/fileLinks` 负责识别、解析、粘贴路径列表与显示；编辑器和变更列表消费这一接口。Windows 路径前缀匹配不区分大小写，Unix 路径保持大小写语义。
- `renderer/platform` 汇集界面平台判断与主快捷键修饰键；主进程继续由 `nativeRuntime` 负责 CLI 和终端选择。没有增加只有一个实现的通用框架。
- SDK 仍只由 `main/sdk` 导入，渲染层通过已有 IPC 契约访问接入与会话操作。插件目录读取留在 `main/skills`，页面不解析磁盘清单。

## Spec

- Mac 登录按钮之前调用 Windows 专属启动逻辑。现在 Mac 显示“复制官方登录命令”，命令正确引用所选引擎路径；Windows 继续提供交互式 PowerShell 登录窗口。安装说明采用通用官方入口。
- Windows 官方 CLI、共享认证与配置、经过接续按钮的会话往返、权限确认、原生终端和额度读取在前序实现中已有本机验收记录。本轮没有重新发送收费模型请求。
- Matt 插件清单的 25 个技能已能读取与展示，主页认证条已移除，任务栏使用裁去透明边距的 Mac 图案。
- 仍有限制：绕过接续按钮，在 CLI 修改桌面仍持有运行实例的会话，不会自动刷新该实例。未实现跨进程会话锁、执行中接管、第三方模型切换或 WSL。本版明确要求先用接续按钮释放桌面实例。
