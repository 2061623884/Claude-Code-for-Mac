# 输入框文件拖拽与附件入口设计

## 目标

让新会话和已有会话共用的 Composer 支持从 Finder 拖入一个或多个文件，并提供与 DeepSeek Harness 附件体验一致的低干扰入口和可移除预览。

## 交互

- Composer 左下角增加圆形“＋”按钮；点击打开系统文件选择器。
- 按钮悬停时加号旋转 90 度并轻微放大；按下或新增附件时扩散一圈强调色反馈。系统启用“减少动态效果”时关闭旋转、缩放和扩散动画。
- 文件拖入窗口时显示覆盖 Composer 的虚线拖放提示；有文件进入时加号高亮，离开或放下后恢复。
- 附件显示在输入框上方，以横向可滚动的标签栏排列。每个标签显示文件名、文件类型、路径提示和“移除”按钮。
- 支持多选、去重和连续拖入；重复文件只保留一份。
- 文件提交成功后清空附件。发送失败时保留附件，避免用户重新选择。
- 拖入非文件内容时忽略，不阻止普通文本拖拽。
- 审批卡出现时已有附件草稿仍然保留；此时输入框可以继续显示，但发送入口在审批完成前保持不可用。

## 数据与路径

- 渲染进程通过 preload 暴露的 `files.pathFor(file)` 调用 Electron `webUtils.getPathForFile()`，兼容 Electron 44 不再支持 `File.path` 的行为。
- 拖拽条目的绝对路径交给主进程 `files.describe(paths)` 校验；只接受普通文件，目录和无法读取的路径被忽略，同时返回文件名、扩展名和大小。
- 附件对象始终保存规范化后的绝对路径。提交时再依据当前项目 `cwd` 计算引用；项目目录内的文件使用相对路径，项目目录外以及无法可靠计算相对路径的文件使用绝对路径。
- 相对路径判断必须包含目录分隔符边界，例如 `/project-other/a.ts` 不能被视为 `/project` 内的相对路径。
- 提交时在用户正文前拼接 `@路径`，每个附件用换行分隔，正文为空时仍可发送附件引用。
- 仅依赖现有纯文本 Agent SDK 消息接口，不上传或复制文件内容。

## 组件边界

- `Composer` 管理拖放状态、加号动效、附件选择和最终提示词拼接，但附件草稿由页面层持有并通过受控属性传入，避免审批卡或条件渲染导致状态丢失。
- 提交回调使用 `{ text, prompt, attachments }`：`text` 保留用户正文，`prompt` 是加入 `@路径` 后的最终 Agent 输入，调用方据此分别设置新会话标题和发送内容。
- 提交回调返回 `Promise<void>`；Composer 仅在它成功完成后清空正文和附件。失败时保留草稿，并允许调用方展示错误。
- 路径归一化、去重和提示词拼接放在 `src/shared/attachments.ts`，供渲染进程复用并由单元测试覆盖。
- `DeskApi.files` 增加 `pathFor(file)` 和 `describe(paths)`；preload 负责 Electron File 到磁盘路径的转换，主进程负责普通文件校验。
- 不修改主进程聊天协议；两个现有调用方继续调用 `onSubmit`。

## 错误与边界

- 空路径、无磁盘文件路径、目录和读取失败的条目不会加入附件栏。
- 附件数量不设硬上限，但标签栏横向滚动，避免撑高输入框。
- 运行中仍允许准备附件；已有发送逻辑决定何时可发送。
- 项目的 `cwd` 缺失时附件保留绝对路径。
- 新会话的待显示标题优先使用用户正文；正文为空时使用附件文件名，不直接使用 `@路径`。

## 视觉

- 参考 DeepSeek Harness：横向附件栏、64px 左右的文件卡片、遮罩式拖放提示、圆形低干扰“＋”按钮。
- 保持 Claude Desk 现有的 20px Composer 圆角、Anthropic 橙强调色和紧凑密度。
- 加号反馈包括短促旋转、1.04 倍缩放和一次扩散环，不做持续闪烁或大幅位移。

## 验证

- 单元测试覆盖项目内相对路径、项目外绝对路径、兄弟目录前缀、重复去除、提示词拼接、空列表和仅附件提交的标题回退。
- 运行 `npm test`、`npm run typecheck`、`npm run build`。
- 启动应用检查新会话和已有会话的点击选择、拖拽提示、多文件、移除和发送后清空。
